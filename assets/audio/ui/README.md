# Staged UI audio

Curated candidates from Kenney's [UI Audio](https://kenney.nl/assets/ui-audio) pack (CC0, see `License.txt`). Nothing here ships with the client — to use a sound, copy it to `packages/client/public/sounds/ui/` and wire it in `game/audio.ts`.

Earmarked uses:

- `rollover1-6` — button/tab hover ticks (wired: `rollover1`)
- `click1-5` — button press / selection confirm (wired: `click1` for every press and pick — keep clicks on one sample for consistency)
- `switch1-6` — drawer open/close (wired: `switch2` open, `switch3` close)
